# Pausa Café

Site institucional e cardápio interativo de uma cafeteria fictícia, desenvolvido como projeto de portfólio. A proposta é apresentar uma identidade visual acolhedora e oferecer uma experiência simples para conhecer o cardápio e montar um pedido demonstrativo.

> **Projeto fictício:** endereço, horários, contato, produtos e pedidos são ilustrativos. Nenhum pedido é enviado ou processado.

## Sobre o projeto

A Pausa Café é uma experiência web para uma cafeteria imaginária. O site reúne uma página inicial com apresentação do espaço, cardápio, informações conceituais sobre a marca e uma página para montar pedidos.

O projeto foi pensado para funcionar em computadores e celulares, com navegação entre páginas, imagens organizadas por categoria e informações sobre os ingredientes e características dos produtos.

## Funcionalidades

- Página inicial com apresentação da cafeteria e acesso às principais seções.
- Cardápio organizado em bebidas quentes, bebidas geladas, salgados e doces.
- Página “Sobre” com a história e a identidade conceitual da Pausa Café.
- Página de pedidos com seleção dos itens e resumo do pedido.
- Opções demonstrativas para consumir no local, retirar ou receber por entrega.
- Formulário de entrega com dados ilustrativos e taxa de R$ 5,00.
- Descrições e avisos sobre glúten, lactose, opções veganas e vegetarianas.
- Layout adaptável para computadores e celulares.
- Avisos informando que o projeto e o fluxo de pedido são fictícios.

## Páginas

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página inicial, cardápio, apresentação e contato |
| `about.html` | Página com informações conceituais e galeria |
| `order.html` | Página demonstrativa para montar um pedido |

## Tecnologias

- HTML
- CSS
- JavaScript

O projeto é estático e não depende de servidor, banco de dados ou serviço de pagamento. A conclusão do pedido é apenas uma demonstração visual.
